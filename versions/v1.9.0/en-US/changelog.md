## What's new

- Added configurable End day options with support for a custom day offset throughout the application
- Added a new What's New popup for application updates
- Improved widget updates and quick-add feedback
- Improved application update and notification handling

## Improvements

- Improved overall application stability and reliability
- Improved Excel import compatibility
- Added support for localized in-app changelogs

## Bug fixes

- Fixed Excel import compatibility when columns are missing
- Improved widget update reliability

## Important

Excel backup format has been updated. It is recommended to restore backups created with version 1.9.0 using version 1.9.0 or later.
