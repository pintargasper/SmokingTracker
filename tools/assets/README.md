# Design Assets

This directory contains source files used to design and maintain the visual assets of SmokingTracker

## Files

### `achievements.af`

Source file for the SmokingTracker achievements artwork

- Editable source file created with [Affinity Designer](https://affinity.serif.com/en-us/designer/)
- Keep the original file in this directory
- Exported assets used by the Android application belong in the appropriate `app/src/main/res/drawable-nodpi/` directory

### `icon.piskel`

Source file for the SmokingTracker pixel art icon

- Created and edited using [Piskel](https://www.piskelapp.com/)
- Keep this file as the editable source
- Exported image used by the Android application belong in the appropriate `app/src/main/res/` directory

## Guidelines

- Keep editable/source design files in this directory
- Do not edit exported assets when the original source file is available
- When changing an asset, update the corresponding exported files in the Android project
- Keep source files under version control so the artwork can be modified later
